# 通用槽钢批量下料模板设计

## 目标

将当前针对单一订单的槽钢六根叠切脚本改造成可复用模板。用户通过 UTF-8 JSON 输入任意长度与数量，程序在 6000 mm、9000 mm 标准槽钢中进行人工优先的整批下料优化，并输出 A3 排版图、CSV 明细和 JSON 校验结果。

## 范围与约束

- 支持任意正整数成品长度和数量；每件长度必须不大于 9000 mm。
- 原料规格由输入文件自定义为一个或多个正整数长度，示例使用 6000 mm 和 9000 mm；单批叠切 1～6 根，同批槽钢使用完全相同的切割顺序。
- 锯缝、最少/最多采购根数、最大叠切根数和人工基线均由输入文件或命令行参数指定。
- 优化目标按以下词典序执行：最少上下料批次、最少落锯次数、最少原料总长、最少切割模式种类。
- 输出不替代结构、工艺、板厚、装配间隙和设备安全复核；程序不得生成 NC/G-code。
- 保留当前订单作为示例输入，不再写入核心代码常量。

## 输入与输出

输入 JSON 包含 `demand`（长度到数量的映射）、`kerf_mm`、`stock_lengths_mm`（可自定义）、`max_stack`、`min_bars`、`max_bars`、`baseline_batches`、`baseline_strokes` 和可选 `title`。

输出目录包含：

- A3 横向 PNG，每页最多 10 个批次；
- UTF-8-SIG CSV，便于现场用 Excel 打开；
- UTF-8 JSON，包含摘要、每批切割顺序和校验统计。

## 组件边界

1. `channel_batch.py` 继续负责批次模型和完整性校验。
2. `channel_batch_optimizer.py` 继续负责 CP-SAT 优化，并暴露通用订单调用接口。
3. `generate_channel_batch_plan.py` 负责输入解析、参数校验、调用优化器和写出结果，不包含订单常量。
4. `skills/channel-cutting-layout/SKILL.md` 提供 Codex 使用说明，引用仓库命令和安全复核规则。
5. README 和示例提供中英文双语入口。

## 验收标准

- 用示例订单运行后，成品数量和各长度数量完全匹配输入，且任何批次余料不得为负。
- 非法 JSON、零/负数量、超长件、非法原料规格和不合理叠切数返回明确错误并退出码 2。
- 现有测试与新增模板测试全部通过，覆盖率保持不低于 85%。
- Skill 通过 `quick_validate.py`，不含 TODO/TBD 等脚手架占位符。
- GitHub 仓库包含中英文 README、模板示例、Skill 包和可复现实验命令。
